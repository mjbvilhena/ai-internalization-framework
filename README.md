# AI Internalization Framework

A tool-agnostic framework designed to help you absorb, understand, and retain projects that were heavily generated by AI. 
This framework is **not coding specific**. It can be applied to software, books, legal research, marketing campaigns, or any complex undertaking where AI has outpaced your mental model.

## The Core Concept: The 5-Phase Protocol

Regardless of the tool you use (agy, Cursor, GHCP, Claude), the internalization agent will follow a strict 5-phase protocol:

1. **Phase 1: Scoping (The Focus)**: The agent uses a 2-tier questioning process to narrow down the focus (structure, topics, or characteristics) and presents selectable options before starting.
2. **Phase 2: Discovery (The "What")**: The agent maps the territory — outlining the core objective, identifying main components, and producing a high-level structural summary of the scoped area.
3. **Phase 3: Mechanics (The "How")**: The agent traces the operational flow — how components interact, how logic or data moves through the system, and surfaces non-obvious dependencies or emergent behaviors.
4. **Phase 4: Deconstruction (The "Why")**: The agent explains the *intent* behind decisions and trade-offs, anchored in the concrete mechanics established in Phase 3.
5. **Phase 5: Interrogation (The Grill)**: The agent flips the script and uses Socratic multiple-choice questioning to test your understanding, correct misconceptions, and loop until the material is fully internalized.

## Installation

This repository contains installation scripts for various agentic harnesses.

### Antigravity (agy)
Installs a global skill to your Antigravity profile.
```bash
./agy/install_agy.sh
```
**Usage:** Ask agy to "internalize this project".

### Cursor
Installs a `.cursor/commands/internalize.md` custom slash command globally (or to a target directory).
```bash
# Install globally for all Cursor projects (default)
./cursor/install_cursor.sh

# Or install to a specific workspace only
./cursor/install_cursor.sh [target_directory]
```
**Usage:** Open the project in Cursor and type `/internalize` in the Agent Chat.

### GitHub Copilot (GHCP)
Installs `.github/copilot-instructions.md` into the target directory.
```bash
./ghcp/install_ghcp.sh [target_directory]
```
**Usage:** Open the project in VS Code with GHCP and ask it to "internalize the project".

### Claude Code
Installs a global `cl-internalize` wrapper script to `~/.local/bin`.
```bash
./claude-code/install_claude.sh
```
**Usage:** Run `cl-internalize` in your terminal within any project directory.
